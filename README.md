# 🎖 ربات مقام (Rank Bot) — The Earth Game

ربات مستقل و ماژولار مدیریت مقام‌ها، رده‌های نظامی و تگ‌های اعضای گروه بازی **The Earth Game**.

---

## 🚀 ویژگی‌های کلیدی
- **مدیریت خودکار و دستی تگ‌های تلگرام (Bot API 9.4+)** با استفاده از متد جدید `setChatMemberTag`.
- **نظام درجه‌بندی ۲۱ سطحی:** از *سرباز صفر* تا *ارتشبد* با تفکیک دقیق رده‌ها (سرباز، درجه‌دار، استوار، افسریار، افسر جوان، افسر ارشد، ژنرال، فرماندهی عالی).
- **اتصال دوطرفه و امن با ربات اصلی بازی:**
  - دریافت وب‌هوک پایان فصل (`/endseason`) با امضای رمزی HMAC-SHA256.
  - دریافت زنده یا دوره‌ای فهرست بازیکنان فعال (`/roster`).
- **قوانین هوشمند ارتقا:**
  - ارتقای خودکار فصلی با سقف سطح ۱۷ (*سرهنگ*).
  - ارتقا و انتصاب مستقیم سطوح بالاتر (تا ۲۱ - *ارتشبد*) منحصراً توسط فرماندهی (مالک).
  - ذخیره‌سازی و بازیابی خودکار مقام برای اعضایی که از گروه خارج شده و دوباره بازمی‌گردند.
- **تولید کارت مقام گرافیکی در رم:** بدون وابستگی خارجی با فونت فارسی وزیرمتن و نوار پیشرفت.
- **سیستم نشان‌ها (Achievements):** پاداش‌دهی خودکار به کهنه‌سربازان و پیشگامان خدمت.
- **پنل شیشه‌ای مدیریت و گزارش‌گیری:** تطبیق تگ‌ها (`/audit`)، تست سلامت سیستم (`/selftest`) و خروجی اکسل/CSV (`/export`).

---

## 🛠 پیش‌نیازها
- پایتون نسخه 3.11 یا بالاتر (تست‌شده روی Python 3.14)
- پایگاه داده PostgreSQL (یا SQLite جهت تست)
- دسترسی ربات در سوپرگروه به عنوان ادمین با دسترسی `can_manage_tags`

---

## 📦 نصب و راه‌اندازی سریع

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. تنظیم متغیرهای محیطی
یک کپی از `.env.example` به نام `.env` بسازید:
```bash
cp .env.example .env
```
مقادیر `BOT_TOKEN`, `OWNER_IDS`, `TARGET_CHAT_ID`, `DATABASE_URL` و `RANK_SYNC_SECRET` را تکمیل کنید.

### ۳. ساخت جداول پایگاه داده
```bash
python scripts/init_db.py
```

### ۴. اجرای ربات
```bash
python -m bot
```
